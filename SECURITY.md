# Security Policy

## Supported Versions

Only support and release security patches for the latest stable release only. Older versions will not receive security fixes.

| Version  | Supported          |
| -------- | ------------------ |
| Latest   | :white_check_mark: |
| < Latest | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

If you discover a security vulnerability or an exploitable flaw in Raysim:

* **Preferred Method:** Use [GitHub Private Vulnerability Reporting](https://github.com/DMsuDev/Raysim/security/advisories/new) to submit a confidential report.
* **Minor Concerns:** For non-critical hardening suggestions, low-impact weaknesses, or insecure default settings, feel free to open an **Issue** or start a **Discussion**.

They will be reviewed as soon as possible.
